# 界王平

蜀势力，男，4 体力。技能：**飞军**、**兵略**。

| 文件 | 作用 |
|---|---|
| `general.json` | 元数据 + 技能列表（`skills: ["飞军", "兵略"]`） |
| `飞军.skill.ts` | **代码**技能：出牌阶段限一次的主动技能，弃牌换对方给牌/弃装备 |
| `兵略.skill.ts` | **代码**技能：`hand_card_lost` 钩子，首次对某目标发动飞军时摸两张牌 |
| `general.md` | 本文件 |

## 技能

- **飞军**（代码，主动）：出牌阶段限一次，你可以弃置一张牌，然后：令一名手牌数大于你的角色交给你一张牌；或令一名装备区里牌数大于你的角色弃置一张装备牌。
- **兵略**（代码，被动）：锁定技，当你对每名其他角色第一次发动"飞军"时，你摸两张牌。

## 用到的 API 与触发点

| 项 | 用法 |
|---|---|
| 技能类型 | 飞军 `kind: "active"` + `requiresTarget: true` + `targetIntent: "enemy"`；兵略 `kind: "passive"`（标记技能，无独立钩子） |
| 飞军限一次 | `canUse` 查 `ctx.skillUsedThisTurn`，`play` 里 `ctx.markSkillUsed(player.id, "飞军")` |
| 飞军代价 | `ctx.requestDiscardSelection(player, 1, reason, 手牌来源限定)` 弃一张手牌（内部已移出手牌），调用方手动 `discardPile.push` |
| 飞军目标条件 | 手牌数大于你，或装备区牌数大于你（武器/防具/防御马/进攻马/宝物，非空计 1）；弃置代价只减自己手牌数，故 getTargets 时成立的条件在 play 时依然成立 |
| 两项都满足 | `ctx.decide({kind: "optional-effect"})` 让玩家二选一（给牌 / 弃装备） |
| 给牌 | 目标用 `requestDiscardSelection` 选一张手牌（内部已移出），调用方不进弃牌堆、改为 `player.hand.push`（与好施给牌同路） |
| 弃装备 | 装备区无 Card 实体，按武器→防具→防御马→进攻马→宝物的固定顺序取首个非空槽位置空，并往弃牌堆补一张合成牌（牌堆计数自洽） |
| 兵略联动 | 引擎没有"技能发动"触发点，故飞军在弃置代价前往 `ctx.skillFlagsThisTurn` 写 `飞军发动:<targetId>` 标记；兵略挂 `hand_card_lost` 钩子，玩家失去手牌时读到标记即结算（首次对该目标发动时摸两张牌），并清除标记；飞军 play 末尾也会清一次作兜底 |
| 兵略跨回合记录 | 模块级 `WeakMap<Player, Set<string>>`（键是本对局玩家对象，每局新建、对局结束即回收，不跨对局泄漏） |

## 已知限制

1. **飞军弃装备无目标选择交互**：引擎无"选装备"请求类型，目标不能自选弃哪件装备，按武器→防具→防御马→进攻马→宝物的固定顺序自动弃首件。
2. **飞军弃装备未触发 `equip_lost` 钩子**：`SkillModuleCtx` 未暴露 `onLoseEquip`，与强袭弃武器同限。

## 规则依据

三国杀界限突破界王平「飞军」「兵略」（兵略为当前 OL 版"对每名其他角色第一次发动飞军时摸两张牌"）。
