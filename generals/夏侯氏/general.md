# 夏侯氏（蜀，女，3 体力）

| 文件 | 作用 |
|---|---|
| `general.json` | 元数据 + 技能列表（`skills: ["樵拾"]`） |
| `樵拾.skill.ts` | **代码**技能：触发技，其他角色结束阶段开始时若手牌数与你相等，双方各摸一张牌 |
| `general.md` | 本文件 |

> 势力更正：队列原写"魏"，经 BWIKI 夏侯氏页与萌娘百科核实为**蜀**（编号 SP.SHU / YJ.SHU），已按官方取蜀。燕语不在队列内，未实现（见已知限制）。

## 技能

- **樵拾**（代码，触发）：其他角色的结束阶段开始时，若其手牌数等于你，你可以令你与其各摸一张牌。

## 用到的 API 与触发点

| 项 | 用法 |
|---|---|
| 技能类型 | `kind: "triggered"` + `triggers: ["end_phase_start"]` + `globalHook: true`（监听其他角色的结束阶段） |
| 持有者定位 | 全局钩子内 `ctx.players.find((p) => p.alive && ctx.hasSkill(p, "夏侯氏/樵拾"))` |
| 条件 | actor 不是持有者本人 + actor 存活 + `actor.hand.length === holder.hand.length`（结束阶段入口在弃牌阶段之后，按弃牌后手牌数比较） |
| 效果 | 可选发动（`shouldActivateOptionalEffect`）后 `ctx.drawCards(holder.id, 1)` + `ctx.drawCards(actor.id, 1)` |

## 已知限制

- **燕语未实现**（队列只列樵拾）：燕语"出牌阶段，你可以重铸【杀】；出牌阶段结束时，若你于此阶段内重铸过两张或更多的【杀】，则你可以令一名男性角色摸两张牌"——重铸本身可用弃牌+摸牌实现，但"出牌阶段结束时"无对应触发点（`end_phase_start` 是结束阶段入口，`discard_phase_start` 是弃牌阶段入口，均非出牌阶段结束），暂不实现。如需补燕语，须先评估新增触发点。
- 界限突破版樵拾（"花色相同可重复此流程"）未采用；本包用经典版/一将成名2015版。

## 验证

- `--strict --selfplay=5` 通过（0 错误 0 警告）。
- 真实对局验证（`/tmp/verify-xiahoushi.mts`）：
- 10 局强制对局（全员夏侯氏）：10 局分出胜负，樵拾 63 次。
- 定向测试 3 项全过：C1 等手牌触发（混合对局：甲夏侯氏 3 手牌、乙白板 3 手牌，乙回合结束时双方各摸 1，甲 4、乙 4，globalHook 生效）；C2 不等不触发（甲 3、乙 2）；C3 自己回合不触发（甲回合结束时不触发）。
- 教训：`initNetworkGame` 恒置 `staged=true`，`endPlayPhase` 只挂起回合结束，`finishTurn`（内含 `end_phase_start`）须由宿主显式消费；定向测试须复刻 `settleStagedTurn` 的消费逻辑，否则结束阶段钩子永不触发（C1 初版因此 FAIL）。
