# 界孙坚

吴势力，男，4 体力。技能：**英魂**。

| 文件 | 作用 |
|---|---|
| `general.json` | 元数据 + 技能列表（`skills: ["英魂"]`） |
| `英魂.skill.ts` | **代码**技能：`turn_start` 事件钩子的完整可执行实现 |
| `general.md` | 本文件 |

## 技能

- **英魂**（代码，触发）：回合开始阶段，若你已受伤，你可以令一名其他角色执行下列两项中的一项：1. 摸 X 张牌，然后弃置一张牌；2. 摸一张牌。X 为你已损失的体力值且至少为 1。

## 用到的 API 与触发点

| 项 | 用法 |
|---|---|
| 触发点 | `turn_start` |
| payload | `payload.actor` = 回合开始的玩家 |
| 归属判定 | `ctx.hasSkill(actor, "界孙坚/英魂")` |
| 可选询问 | `ctx.shouldActivateOptionalEffect(actor, "界孙坚/英魂")` |
| 摸牌 | `ctx.drawCards(playerId, n)` |
| 弃牌 | `ctx.requestDiscardSelection(player, 1, reason)`（返回的牌**不会**自动进弃牌堆，调用方手动 `ctx.discardPile.push`） |

## 已知限制（引擎无交互式选角/二选一，均已文档化自动口径）

1. **目标角色自动挑选**：其他存活角色里手牌最少者优先，手牌相同按 id 升序（与荀彧「节命」口径一致），保证 `--seed` 复现。
2. **两项二选一固定策略**：X >= 2 时执行第 1 项（摸 X 弃 1，净赚 X-1 张）；X == 1 时执行第 2 项（摸 1 张；此时第 1 项净赚 0 张无意义）。这是确定性最优策略，无随机性。

## 规则依据

三国杀官方孙坚「英魂」。本包为完整复刻，仅把"选人+二选一"按上述确定性口径自动化，无数值简化。
