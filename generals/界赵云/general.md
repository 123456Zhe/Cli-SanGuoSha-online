# 界赵云

蜀势力，男，4 体力。技能：**龙胆**、**涯角**。

| 文件 | 作用 |
|---|---|
| `general.json` | 元数据 + 技能列表（`skills: ["龙胆", "涯角"]`） |
| `龙胆.skill.json` | **声明式**技能：杀↔闪、酒→桃转换 |
| `涯角.skill.ts` | **触发性**技能：回合外用牌后展示牌堆顶、按类别给牌或弃置 |
| `general.md` | 本文件 |

## 技能

- **龙胆**（声明式，转换）：你可以将一张杀当闪、闪当杀、酒当桃使用或打出。
- **涯角**（触发性）：当你于回合外使用或打出一张手牌时，你可以展示牌堆顶的一张牌，若此牌与你使用的牌类别相同，你可以将此牌交给一名角色，否则你将此牌置入弃牌堆。

## 已知限制

1. **龙胆“桃当酒”暂不支持**：转换目标 `to` 只放行杀/火杀/雷杀/桃/闪/无懈可击（见 `docs/generals-pack-api.md`“当牌转换”一节），酒不在放行列表，loader 会报错，故本包只实现杀当闪、闪当杀、酒当桃三条，缺的一条如实记录（与界诸葛瞻“父荫”只实现成为杀目标部分同例）。
2. **涯角给牌目标自动交给自己**：触发钩子没有交互选目标（`InteractionRequest` 无选玩家类型），故类别相同时自动交给持有者本人，而非玩家自选一名角色。
3. **涯角“手牌”口径**：`card_used` 钩子不带牌的来源区域，本包按钩子触发即视为手牌用牌处理，与奔袭同口径。
4. **类别推导**：牌面只有 type 字段，类别按基本牌/装备牌/其余归锦囊牌推导（含乐不思蜀、兵粮寸断、闪电等延时锦囊归锦囊牌）。

## 规则依据

三国杀界限突破界赵云「龙胆」：你可以将一张杀当闪、闪当杀、桃当酒、酒当桃使用或打出；「涯角」：当你于回合外使用或打出一张手牌时，你可以展示牌堆顶的一张牌，若此牌与你使用的牌类别相同，你可以将此牌交给一名角色，否则你将此牌置入弃牌堆。
