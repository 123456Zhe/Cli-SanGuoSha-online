# 魏杜预（魏，男，4 体力）

| 文件 | 作用 |
|---|---|
| `general.json` | 元数据 + 技能列表（`skills: ["谏国", "倾势"]`） |
| `谏国.skill.ts` | **代码**技能：主动技，出牌阶段每项限一次，令一名角色摸1弃半或弃1摸半 |
| `倾势.skill.ts` | **代码**技能：触发技，回合内用杀/锦囊指定目标且为本回合第 X 张牌（X=手牌数）时对目标造成 1 点伤害 |

> 版本：SP 魏杜预现行版（2024-01-31 调整后）。原版（2023）谏国为"出牌阶段限一次……（向下取整）"，2024-01-31 调整为每项限一次、向上取整；本包用现行版。与已上架的群杜预（武库/三陈/灭吴）为不同版本武将。

## 技能

- **谏国**（代码，主动）：出牌阶段每项限一次，你可以令一名角色摸一张牌，然后弃置一半数量的手牌；或令其弃置一张牌，然后摸当前手牌数一半数量的牌。（向上取整）
- **倾势**（代码，触发）：当你于回合内使用【杀】或锦囊牌指定目标后，若此牌为你本回合使用的第X张牌（X为你的手牌数），你可以对一名其他目标角色造成1点伤害。

## 用到的 API 与触发点

| 项 | 用法 |
|---|---|
| 谏国限次 | 每项各限一次：`ctx.skillUsedThisTurn` 里记 "魏杜预/谏国·摸弃" / "魏杜预/谏国·弃摸" 两个 key；`canUse`/`getTargets` 按分支查 |
| 谏国弃牌 | 弃牌均由目标本人选择：`requestDiscardSelection(target, n, reason)`（不传预置 sources，逐张重建候选）；返回的牌走 `ctx.discardCards` 进弃牌堆（发 `card_discarded` 触发点） |
| 谏国取整 | X 向上取整（`Math.ceil`），在第二步结算时按目标当时手牌数算 |
| 倾势触发点 | `triggers: ["turn_start", "card_used"]`；`turn_start` 清零计数，`card_used`（reason="使用"）计数+1 后判定 |
| 倾势目标 | `payload.targets`（引擎 2026-11-14 提交 153b377 新增字段）：含其他角色才可触发；伤害目标为 targets 中除自己外的第一名（id 升序） |
| 倾势计数 | 模块级 WeakMap<Player, number>；计所有"使用"过的牌（桃/酒/装备也计），不计"打出"；只计持有者自己回合内（`ctx.currentPlayer.id === actor.id`） |
| 倾势伤害 | `ctx.applyDamage(actor, victim, 1, "倾势", logs, card)`；不单独结算死亡，由原牌结算后的统一死亡结算处理 |

## 已知限制

- **谏国分支自动选择**：引擎主动技能没有"二选一"交互，两项由技能按目标自动选——目标是自己且手牌数 ≥ 2 时执行"弃1摸半"（补给向），其余执行"摸1弃半"（削弱向）。无法对队友执行"弃1摸半"，也无法对敌人执行"弃1摸半"（如过牌找关键牌）。
- **倾势依赖新引擎**：`payload.targets` 由引擎提交 153b377（2026-11-14）提供；生产 host 须先拉新引擎代码并重启，否则旧引擎 payload 无 targets 字段、倾势不触发。谏国不依赖新引擎。
- 倾势伤害目标自动挑选（targets 中除自己外的第一名，id 升序），玩家不能自选。
- 倾势伤害不单独结算死亡：钩子在原牌结算前发出，伤害先造成、死亡结算在原牌结算后统一处理；极端情况下濒死目标仍可响应原牌（如出闪）。
- 倾势计数的"使用"含当牌转换的使用（走同一 resolveUsedCard 路径），与官方"使用牌"口径一致。

## 验证

- `--strict --selfplay=5` 通过（0 错误 0 警告）。
- 真实对局验证（`/tmp/verify-weiduyu.mts`）：
- 10 局强制对局（全员魏杜预）：10 局分出胜负，倾势 62 次；谏国 0 次——启发式 AI 从不选主动技能，属 AI 行为而非技能问题（见 A2）。
- 5 局谏国优先对局（驱动优先选谏国）：5 局分出胜负，谏国摸弃 91 次、弃摸 89 次，0 崩溃。
- 定向测试 6 项全过：B1 谏国摸弃数学（4 手牌→摸1→弃3→剩2）；B2 谏国弃摸数学（4 手牌→弃1→摸2→剩5）；B3 每项限一次（用过摸弃后该分支目标不可选、另一分支仍可用，两项用完技能消失）；B4 倾势触发（第 2 张牌=手牌数 2，决斗不触发、杀触发，伤害结算正确）；B5 不触发对照（第 1 张牌≠手牌数 3）；B6 自目标不触发（铁索连环指定自己不触发，随后杀触发）。
