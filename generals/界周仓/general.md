# 界周仓

蜀势力，男，4 体力。技能：**忠勇**。

| 文件 | 作用 |
|---|---|
| `general.json` | 元数据 + 技能列表（`skills: ["忠勇"]`） |
| `忠勇.skill.ts` | **代码**技能：`slash_targeted` 钩子，出牌阶段使用【杀】指定目标后令其弃一张手牌（【决斗】分支暂未实现，见已知限制） |
| `general.md` | 本文件 |

## 技能

- **忠勇**（代码，触发）：当你于出牌阶段内使用【杀】或【决斗】指定目标后，你可以令其弃置一张牌。

## 用到的 API 与触发点

| 项 | 用法 |
|---|---|
| 技能类型 | `kind: "triggered"` + `triggers: ["slash_targeted"]` |
| 时机 | `slash_targeted` 在指定目标时触发，payload 里 `source` 为出杀者、`target` 为被杀目标——正好对应"使用【杀】指定目标后"（闪响应之前） |
| 出牌阶段内 | `ctx.currentPlayer.id === source.id && ctx.phase === "出牌阶段"` 精确判断，其他阶段出杀不触发 |
| 可选发动 | `ctx.shouldActivateOptionalEffect(source, "界周仓/忠勇")` 询问出杀者，AI 按策略回答 |
| 弃牌 | 目标自己选一张手牌弃置（`requestDiscardSelection(target, …)`，返回的牌调用方手动 `discardPile.push`，与飞军代价同一约定） |
| 不取消杀 | 不改写 `payload.canceled`，忠勇只令目标弃牌、不取消本次杀 |

## 已知限制

【决斗】分支暂未实现：引擎目前没有决斗指定目标的触发钩子，本包仅实现【杀】分支；待钩子补齐后再补【决斗】分支。除此之外，【杀】分支为完整实现。

## 规则依据

三国杀界限突破界周仓「忠勇」：当你于出牌阶段内使用【杀】或【决斗】指定目标后，你可以令其弃置一张牌。
