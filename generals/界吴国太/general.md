# 界吴国太（吴，女，3 体力）

| 文件 | 作用 |
|---|---|
| `general.json` | 元数据 + 技能列表（`skills: ["甘露"]`） |
| `甘露.skill.ts` | **代码**技能：主动技，出牌阶段限一次，选两名装备数之差 ≤ 已损失体力的角色交换全部装备 |
| `general.md` | 本文件 |

## 技能

- **甘露**（代码，主动）：出牌阶段限一次，你可以选择两名装备区里的牌数之差不大于你已损失体力值的角色，交换他们装备区里的牌。

## 用到的 API 与触发点

| 项 | 用法 |
|---|---|
| 技能类型 | `kind: "active"` + `canUse` / `getTargets` / `play` |
| 限一次 | `canUse` 查 `skillUsedThisTurn`，`play` 里 `markSkillUsed` |
| 装备数 | 武器/防具/防御马/进攻马/宝物五个非空槽位计数 |
| 已损失体力 | `maxHp - hp`（吴国太本人） |
| 交换 | 五个槽位直接赋值互换 + `treasureCards`（木牛内牌）跟随宝物互换 |

## 已知限制

- 引擎主动技能只支持单目标选择（`getTargets` + `play(targetId)`），无法让玩家依次选两名角色：本包由玩家选第一名角色，第二名角色自动挑选（满足条件的其他存活角色中装备数最多者，并列 id 升序），getTargets 只返回存在有效搭档的第一名角色候选。
- 装备交换用槽位直接赋值（与飞军弃装备同一约定），不触发 `equip_lost` / 装备获得钩子。
- 采用一将成名版甘露（装备数之差限制始终适用）；移动版"若选择的角色含有你则不受限制"未采用。
