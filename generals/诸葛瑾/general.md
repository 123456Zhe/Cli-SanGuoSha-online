# 诸葛瑾（吴，男，3 体力）

| 文件 | 作用 |
|---|---|
| `general.json` | 元数据 + 技能列表（`skills: ["弘援"]`） |
| `弘援.skill.ts` | **代码**技能：触发技，摸牌阶段少摸一张，令至多两名其他角色各摸一张 |
| `general.md` | 本文件 |

## 技能

- **弘援**（代码，触发）：摸牌阶段，你可以少摸一张牌，然后令至多两名其他角色各摸一张牌。

## 用到的 API 与触发点

| 项 | 用法 |
|---|---|
| 技能类型 | `kind: "triggered"` + `triggers: ["before_draw"]` + `onTrigger.before_draw` |
| 确认持有者 | `ctx.hasSkill(player, "诸葛瑾/弘援")`（命名空间形式） |
| 可选发动 | `shouldActivateOptionalEffect(player, "诸葛瑾/弘援")` |
| 少摸一张 | 改写 `payload.drawCount`（-1） |
| 他人摸牌 | `ctx.drawCards(targetId, 1)` |

## 已知限制

- 采用王者之战2019 / 将星归汉、OL 版弘援（摸牌阶段少摸一张、令至多两名其他角色各摸一张）；2024珍藏版改版（一次获得≥2 张后给牌）因无获得牌触发点且需多目标给牌，未采用。
- 无交互选人：受益角色自动挑至多两名其他存活角色（id 顺序），不由玩家自选。
- 体力上限按 Fandom 页取 3（队列原写 4，已更正）。
