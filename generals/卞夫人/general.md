## 技能

- **挽危**（代码，主动+触发）：每轮限一次，出牌阶段，你可以令一名其他角色回复X+1点体力；一名其他角色进入濒死状态时，你可以令其回复X+1点体力（若其脱离濒死状态需回复的体力值大于X+1则改为将体力回复至1点），然后你失去X点体力（X为你的体力值）。
- **约俭**（代码，锁定+触发）：你的手牌上限等于你的体力上限；当你进入濒死状态时，你可以弃置两张牌，然后回复1点体力。

## 用到的 API 与触发点

| 项 | 用法 |
|---|---|
| 技能类型 | 挽危 `kind: "active"` + `triggers: ["dying"]` + `onTrigger.dying` + `globalHook: true`；约俭 `kind: "triggered"` + `triggers: ["dying"]` |
| 每轮限一次 | `ctx.isSkillUsedThisRound(player.id, "挽危")` 查、`ctx.markSkillUsedThisRound` 记（Phase 9，轮次回到起始座位时引擎自动清空） |
| 濒死分支 | `dying` 钩子（桃救援之前发出）；挽危用 `globalHook` 监听其他角色濒死，钩子内自行定位持有者 |
| 回复结算 | 需回复量 = 1 - 濒死者当前体力，大于 X+1 时直接把体力置为 1 点，否则回复 X+1 点（封顶体力上限）；回血直接改 `hp` |
| 自损结算 | 出牌阶段分支自损后走 `resolveDeaths`/`resolveWinner`/`advanceIfCurrentPlayerDead`（与苦肉同口径）；濒死分支钩子内不调 `resolveDeaths`，引擎在同一次死亡结算里重扫处理 |
| 手牌上限 | 约俭 `handLimit` 纯函数返回 `maxHp - hp`（与神赵云绝境同一写法），上限 = 体力上限 |
| 弃置代价 | 约俭 `requestDiscardSelection(actor, 2, reason)` 不传预置 sources（让引擎每轮重建来源，避免 count>1 复用旧列表；与结姻同口径），返回的牌手动进弃牌堆 |

## 已知限制

- 挽危出牌阶段分支仅受伤的其他角色可选为目标（满血目标回复无效果，结姻同口径）。
- 约俭弃置仅限手牌与木牛内牌（`buildUsableSources` 默认范围，装备区不在候选里）。
- 约俭无次数限制，每次进入濒死都可发动（官方文本如此）。
