# 界诸葛瞻

蜀势力，男，3 体力。技能：**父荫**。

| 文件 | 作用 |
|---|---|
| `general.json` | 元数据 + 技能列表（`skills: ["父荫"]`） |
| `父荫.skill.ts` | **代码**技能：`slash_targeted` 钩子，每回合第一次成为杀目标且手牌不多于出杀者时此杀无效 |
| `general.md` | 本文件 |

## 技能

- **父荫**（代码，触发）：锁定技，你每回合第一次成为或的目标后，若你的手牌数不大于该角色，此牌对你无效。

## 用到的 API 与触发点

| 项 | 用法 |
|---|---|
| 技能类型 | `kind: "triggered"` + `triggers: ["slash_targeted"]` |
| 每回合第一次 | `ctx.skillCountsThisTurn` 的 `父荫` key 计次（引擎每回合自动重置）；钩子先标记已结算，再判断手牌条件——即"第一次"只评估一次，若手牌条件不满足，本回合不再重复判断 |
| 手牌比较 | `target.hand.length <= source.hand.length` |
| 此牌无效 | 对置 `payload.canceled = true`（钩子文档约定的取消方式） |
| 锁定技 | 不询问，直接生效 |

## 已知限制

1. **成为目标的部分暂不支持**：决斗指定目标没有对应钩子（只有 `slash_targeted`），故本包只实现"成为目标"的部分。

## 规则依据

三国杀界诸葛瞻「父荫」（2020 版）：锁定技，你每回合第一次成为或的目标后，若你的手牌数不大于该角色，此牌对你无效。除上述如实记录的限制外完整复刻。
