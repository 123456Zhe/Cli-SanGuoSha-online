# 界马谡（蜀，男，3 体力）

| 文件 | 作用 |
|---|---|
| `general.json` | 元数据 + 技能列表（`skills: ["心战"]`） |
| `心战.skill.ts` | **代码**技能：主动技，出牌阶段限一次，手牌数大于体力上限时看牌堆顶三张，取红桃、其余放回牌堆顶 |
| `general.md` | 本文件 |

## 技能

- **心战**（代码，主动）：出牌阶段，若你的手牌数大于你的体力上限，你可以观看牌堆顶的三张牌，然后展示其中任意数量♥的牌并获得之，其余以任意顺序置于牌堆顶。每回合限一次。

## 用到的 API 与触发点

| 项 | 用法 |
|---|---|
| 技能类型 | `kind: "active"` + `canUse` / `play`（无目标，不设 `requiresTarget` / `getTargets`） |
| 限一次 | `canUse` 查 `skillUsedThisTurn`（plain "心战"，与飞军同一约定），`play` 里 `markSkillUsed` |
| 条件 | `player.hand.length > player.maxHp` |
| 看牌堆顶 | `ctx.drawTopCards(3)`（取走牌堆顶；心战的获得/放回与取走等价） |
| 放回牌堆顶 | `ctx.placeCardsOnTop(rest)`（原序放回） |

## 已知限制

- 无按花色选子集的交互：红桃自动全取（"任意数量"的一合法选择），不由玩家自选展示张数。
- 其余牌以原序放回牌堆顶（"任意顺序"的一合法选择），不由玩家自选顺序。
- 采用一将成名版心战；桌游志 56 期版已改为散谣/制蛮，未采用。
