# 界骆统

吴势力，男，4 体力。技能：**勤政**。

| 文件 | 作用 |
|---|---|
| `general.json` | 元数据 + 技能列表（`skills: ["勤政"]`） |
| `勤政.skill.ts` | **代码**技能：`card_used` 钩子，3/5/8 里程碑获得牌 |
| `general.md` | 本文件 |

## 技能

- **勤政**（代码，触发）：锁定技，你每使用或打出三张牌时，你随机获得一张或；每使用或打出五张牌时，你随机获得一张或；每使用或打出八张牌时，你随机获得一张或。

## 用到的 API 与触发点

| 项 | 用法 |
|---|---|
| 技能类型 | `kind: "triggered"` + `triggers: ["card_used"]` |
| 使用/打出计次 | `card_used` 的 payload 里 `reason` 为"使用"或"打出"，两者都计入；计次存在 `ctx.skillCountsThisTurn.get(actor.id)` 的 `勤政计数` key 里（引擎每回合自动重置） |
| 里程碑 | 计次恰好达到 3 / 5 / 8 时各获得一次（每回合每档一次，不重复触发）；3 张→随机/，5 张→随机/，8 张→随机/ |
| 随机获得 | 引擎未向武将包暴露创牌接口，故直接合成 Card 对象置入手牌：类型用 `ctx.randomIndex` 二选一；花色用 `ctx.randomIndex` 四选一（红桃/方块为红，梅花/黑桃为黑）；点数用 `ctx.randomIndex(13) + 1`；合成牌 id 形如 `qinzhen-<类型>-<interactionId>` |
| 锁定技 | 不询问，直接生效 |

## 已知限制

无。本包为界骆统移动版「勤政」的完整复刻（里程碑按"每回合每档一次"理解，见技能注释）。

## 规则依据

三国杀界骆统（移动版）「勤政」：锁定技，你每使用或打出三张牌时，你随机获得一张或；每使用或打出五张牌时，你随机获得一张或；每使用或打出八张牌时，你随机获得一张或。
