# 群杜预（群，男，4 体力）

| 文件 | 作用 |
|---|---|
| `general.json` | 元数据 + 技能列表（`skills: ["武库", "三陈"]`，`latentSkills: ["灭吴"]`） |
| `wuku-state.ts` | 共享模块（非技能文件）：武库标记（上限 3）+ 三陈觉醒标志，WeakMap 存 |
| `武库.skill.ts` | **代码**技能：触发技，`card_used` + `equip_lost`，`globalHook: true` |
| `三陈.skill.ts` | **代码**技能：触发技，`prepare_phase_start` + `end_phase_start`，觉醒授灭吴 |
| `灭吴.skill.ts` | **代码**技能：转换技，潜在技能，18 条转换 + 门控/扣费钩子 |
| `general.md` | 本文件 |

## 技能

- **武库**（代码，锁定技）：当你使用装备牌时或其他角色失去装备区内的一张牌时，你获得1枚“武库”标记（至多为3）。
- **三陈**（代码，觉醒技）：准备阶段或结束阶段，若你的“武库”标记数为3，你加1点体力上限，回复1点体力，获得“灭吴”。
- **灭吴**（代码，转换技，对局中获得）：每回合每种牌名限一次，你可以移去1枚“武库”标记，然后将一张牌当任意一种基本牌或普通锦囊牌使用或打出。

## 用到的 API 与触发点

| 项 | 用法 |
|---|---|
| 技能类型 | 武库/三陈 `kind: "triggered"` + `onTrigger`；灭吴 `kind: "conversion"` + `conversions` |
| 新触发点 | `prepare_phase_start` / `end_phase_start`（Phase 8 新增，回合首尾发射，payload.actor 为当前回合玩家） |
| 全局钩子 | 武库 `globalHook: true`（`equip_lost` 的 actor 是失去者不是持有者，默认过滤会拦掉；钩子内用 `ctx.players.find(hasSkill)` 定位持有者） |
| 潜在技能 | `general.json` 的 `latentSkills: ["灭吴"]`（加载注册、不开局持有；三陈觉醒时把 `群杜预/灭吴` push 进 `player.skills`） |
| 转换门控/扣费 | 灭吴 `canUseConversion`（纯门控：标记 ≥1 且本回合该牌名未用过）+ `onConversionUsed`（成功后移去 1 枚标记、计数 +1）；计数键 `灭吴:<牌名>` 存 `ctx.skillCountsThisTurn`（每回合自动清零） |
| 共享状态 | `wuku-state.ts`：`getMarks` / `addMark` / `consumeMark` / `isAwakened` / `setAwakened`，WeakMap |

## 已知限制

- 换武器时只计 1 枚：`card_used` 计使用，`equip_lost` 不计自己失装（防双计）；自己装备被拆/被顺也不计（文本只说"其他角色"）。
- 拆/顺经灭吴当出时，目标牌选择走随机（转换动作不带选牌步骤，与 AI 出牌兜底同口径）。
- 翻面跳过回合时 `prepare_phase_start` 仍会发射（引擎已知的小偏差），三陈会在该准备阶段判定一次。
- 技能名用简体（武库/三陈/灭吴），与项目其余武将包一致；官方文本为繁体（武庫/三陳/滅吳），见下。
