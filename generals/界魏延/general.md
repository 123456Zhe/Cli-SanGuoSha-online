# 界魏延

蜀势力，男，4 体力。技能：**狂骨**。

| 文件 | 作用 |
|---|---|
| `general.json` | 元数据 + 技能列表（`skills: ["狂骨"]`） |
| `狂骨.skill.ts` | **代码**技能：`after_damage` 事件钩子的完整可执行实现 |
| `general.md` | 本文件 |

## 技能

- **狂骨**（代码，触发）：每当你对一名角色造成 1 点伤害后，你可以回复 1 点体力或摸一张牌。

## 用到的 API 与触发点

| 项 | 用法 |
|---|---|
| 触发点 | `after_damage` |
| payload | `payload.source` = 伤害来源；`payload.target` = 受伤者 |
| 归属判定 | `ctx.hasSkill(source, "界魏延/狂骨")`（对自己造成伤害也算，官方口径） |
| 可选询问 | `ctx.shouldActivateOptionalEffect(source, "界魏延/狂骨")` |
| 回血 | 直接 `source.hp = Math.min(source.maxHp, source.hp + 1)`（增益型触发，不走濒死结算路径） |
| 摸牌 | `ctx.drawCards(source.id, 1)` |

## 已知限制

1. **二选一固定策略**：已受伤则回血，满血则摸牌（确定性口径，无随机性）。
2. **触发粒度**：官方是"每造成 1 点伤害"触发一次；本实现按每次伤害事件触发一次（多点伤害的一次事件只触发一次），避免连续多次询问拖慢对局。数值期望基本一致。

## 规则依据

三国杀界限突破魏延「狂骨」。除上述触发粒度简化外完整复刻。
