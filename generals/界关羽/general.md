# 界关羽

蜀势力，男，4 体力。技能：**武圣**。

| 文件 | 作用 |
|---|---|
| `general.json` | 元数据 + 技能列表（`skills: ["武圣"]`） |
| `武圣.skill.json` | **声明式**技能：红色牌当使用或打出 |
| `general.md` | 本文件 |

## 技能

- **武圣**（声明式，转换）：你可以将一张红色牌当使用或打出。

## 用到的 API

| 项 | 用法 |
|---|---|
| 技能类型 | `kind: "conversion"`，纯声明、无代码（参照神赵云「龙魂」的写法） |
| 转换规则 | `conversions: [{ from: { color: ["red"]}, to: "杀", asResponse: ["slash"]}]`——红色牌（红桃/方块）当；`asResponse: ["slash"]` 使其既可在出牌阶段主动使用，也可在需要响应时打出（如决斗、南蛮入侵的响应） |
| 可选发动 | `optional: true`，与龙魂一致 |

## 已知限制

无。本包为界关羽「武圣」的完整复刻（杀次数、目标合法性等由引擎在 `playAction` 复算，与内置转换技同一路径）。

## 规则依据

三国杀界限突破界关羽「武圣」：你可以将一张红色牌当使用或打出。
