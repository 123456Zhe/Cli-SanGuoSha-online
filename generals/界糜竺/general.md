# 界糜竺（蜀，男，3 体力）

| 文件 | 作用 |
|---|---|
| `general.json` | 元数据 + 技能列表（`skills: ["资援"]`） |
| `资援.skill.ts` | **代码**技能：主动技，出牌阶段限一次，交点数和为 13 的手牌子集给一名其他角色并令其回 1 血 |
| `general.md` | 本文件 |

## 技能

- **资援**（代码，主动）：出牌阶段限一次，你可以将任意张点数之和为 13 的手牌交给一名其他角色，然后该角色回复 1 点体力。

## 用到的 API 与触发点

| 项 | 用法 |
|---|---|
| 技能类型 | `kind: "active"` + `canUse` / `getTargets` / `play` |
| 限一次 | `canUse` 查 `skillUsedThisTurn`（plain "资援"，与飞军同一约定），`play` 里 `markSkillUsed` |
| 给牌 | 子集牌用 `removeHandCardAt` 逐张移出手牌（触发失去手牌钩子），再 push 到目标手牌 |
| 回血 | 引擎无回血接口，直接改 `hp` 并封顶到 maxHp |

## 已知限制

- 无按点数和选子集的交互：给牌子集自动挑选（点数之和恰为 13、张数最少者），不由玩家自选。
- 仅手牌可给，木牛内牌不给（FAQ）。
- 回血用直接改 `hp` 并封顶（无回血接口）；出牌阶段使用、目标非濒死，无需死亡结算；满血目标回血无效果（FAQ）。
- 巨贾不在队列范围内（队列只含资援），未实现。
