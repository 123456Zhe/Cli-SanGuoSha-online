# 界曹冲（魏，男，3 体力）

| 文件 | 作用 |
|---|---|
| `general.json` | 元数据 + 技能列表（`skills: ["称象"]`） |
| `称象.skill.ts` | **代码**技能：触发技，受伤后亮牌堆顶四张，获得其中点数和 ≤13 的子集 |
| `general.md` | 本文件 |

## 技能

- **称象**（代码，触发）：当你受到伤害后，你可以亮出牌堆顶的四张牌，然后你获得其中的任意张点数之和不大于 13 的牌。

## 用到的 API 与触发点

| 项 | 用法 |
|---|---|
| 技能类型 | `kind: "triggered"` + `triggers: ["after_damage"]` |
| 受伤确认 | `payload.target` 为受伤者，`ctx.hasSkill(target, "界曹冲/称象")` 确认是曹冲受伤（镇卫同一约定） |
| 可选发动 | `ctx.shouldActivateOptionalEffect` 询问 |
| 亮牌堆顶 | `ctx.drawTopCards(4)`（取走牌堆顶；称象的获得/弃置与取走等价） |
| 获得/弃置 | 获得直接 push 到手牌；其余 `discardPile.push` |

## 已知限制

- 无按点数约束选子集的交互：获得的子集自动挑选（点数和最大且 ≤13，并列取张数多者），不由玩家自选。
- 2014 版未明说余牌去向，按 2013 版"将其余的牌置入弃牌堆"处理。
- 采用一将成名 2014 版（点数和不大于 13）；2013 版"小于 13"未采用。
- 无每回合次数限制，每次受伤均可触发。
