# 曹植（魏，男，3 体力）

| 文件 | 作用 |
|---|---|
| `general.json` | 元数据 + 技能列表（`skills: ["落英"]`） |
| `落英.skill.ts` | **代码**技能：触发技，其他角色的梅花牌因判定或弃置进入弃牌堆时获得之 |
| `general.md` | 本文件 |

> 酒诗不在队列内，未实现（见已知限制）。

## 技能

- **落英**（代码，触发）：当其他角色的梅花牌因判定或弃置而进入弃牌堆时，你可以获得之。

## 用到的 API 与触发点

| 项 | 用法 |
|---|---|
| 技能类型 | `kind: "triggered"` + `triggers: ["card_discarded"]` + `globalHook: true`（监听其他角色弃牌/判定） |
| 持有者定位 | 全局钩子内 `ctx.players.filter((p) => p.alive && ctx.hasSkill(p, "曹植/落英"))`，按座位顺序逐个询问，直到有人获得或全部拒绝 |
| 条件 | `payload.card.suit === "club"`（梅花）+ `payload.actor.id!== holder.id`（其他角色）+ 牌仍在 `ctx.discardPile` 中（多曹植同局时先获得者已取走，后触发者须跳过；先查弃牌堆再询问，避免无效提问） |
| 效果 | 可选发动（`shouldActivateOptionalEffect`）后按 id 从 `ctx.discardPile` splice 取出并 push 进持有者手牌（与内置天妒同一取牌方式） |
| 依赖 | **Phase 10 引擎**：`card_discarded` 触发点 + `discardCards` 中央入口；旧引擎上不触发 |

## 已知限制

- **酒诗未实现**（队列只列落英）：酒诗"当你需要使用【酒】时，若你的武将牌正面朝上，你可以视为使用一张【酒】；当你受到伤害后，若此时与你受到此伤害时你的武将牌均背面朝上，你可以（将武将牌翻至正面）"——需"需要使用酒"的响应时机 + 翻面联动，暂不实现。如需补酒诗，须先评估响应时机接口。
- **落英先于天妒获得是既定顺序**：判定牌在判定结算前即入堆，`card_discarded` 在入堆时发出；内置天妒在判定结算后才取牌。曹植与张角同局、判定牌为梅花时，落英先获得，天妒取不到（官方同类触发按座位顺序处理，引擎简化为落英优先）。
- 弃置装备的牌不触发落英：装备区无 Card 实体，弃置装备时引擎只补一张花色为 none 的合成牌进弃牌堆，落英按花色过滤自然排除（与官方"装备牌有花色"的口径有差距，属引擎既定限制）。
- 展示后置入弃牌堆的牌（如涯角/称象未获得的牌）不触发落英：不是"弃置"，与官方口径一致。

## 验证

- `--strict --selfplay=5` 通过（0 错误 0 警告）。
- 真实对局验证（`/tmp/verify-caozhi.mts`）：
- 10 局强制对局（全员曹植）：10 局分出胜负，落英 19 次（弃置与判定两种来源均有出现）。
- 定向测试 4 项全过：D1 他人弃梅花获得（混合对局：甲曹植、乙白板弃梅花杀，甲获得、牌不在弃牌堆，globalHook 生效）；D2 他人弃非梅花不触发；D3 自己弃梅花不触发（牌留在弃牌堆）；D4 判定梅花获得（牌堆顶梅花桃，乙判定，甲获得）。
